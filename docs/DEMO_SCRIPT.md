# Three-minute demo script

- 0:00–0:20 — A critical report should not force identity and wallet-history disclosure.
- 0:20–0:50 — Show program policy, fixed tiers, deadlines and the visible privacy boundary.
- 0:50–1:30 — Enter a report, encrypt locally, show commitments and export recovery package; emphasize “Not submitted” until receipt.
- 1:30–2:00 — Show vendor acknowledgement and acceptance plus committed timestamps.
- 2:00–2:30 — Authorize one fixed tier and claim through the STRK20 pool into an open note.
- 2:30–2:50 — Open explorer receipts and run the evidence verifier for pool + project events.
- 2:50–3:00 — Close on the differentiation: reserve, deadlines, one-time settlement, reusable receipts.
