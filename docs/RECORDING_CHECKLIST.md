# Recording checklist

- Fresh browser profile; no unrelated tabs, accounts, names or notifications.
- Demo URL public without login; zoom and audio legible; three minutes maximum.
- Use a dedicated low-value wallet; never expose recovery/seed/private/viewing keys.
- Show live network and explorer; distinguish fixtures, Sepolia and mainnet.
- Verify all three hashes before recording; avoid cuts that imply nonexistent success.
- Upload publicly, verify anonymous playback, then add the real URL to `strk20.json`.
